# 关于本站：鱼心快跑与这本手册

<BrandMark variant="card" />

## 为什么做这一本站

因为每次有人问"Forward Deployed Engineer 是什么"，得到的答案要么是厂商招聘页原文，要么是自媒体的"年薪百万不是梦"。两种都对不上"我到底该不该转"这个真实问题。

这个岗位的公开信息有个特点：<strong>数字很多，能用的很少。</strong>同一家公司的两份 JD 能写出两种差旅比例；同一个"国内 FDE 平均月薪"有四种互不兼容的算法；面试轮次有四种版本；失败率有四组口径完全不同的数字。

所以本站的做法不是"给出结论"，而是**把材料摆齐、把口径写明、把读不到的地方标成读不到**。这比一个漂亮答案更有用，因为它能被你拿去复核。

## 品牌：一条会跑、还会架桥的鱼

**鱼心快跑**（Yuxin Runs）是这个系列的署名，取自"余心快跑"的谐音，兼作 GitHub 用户名。整套命名走的是"有画面感的自嘲"而不是"正经技术品牌"，所以你在正文里会看到"提着行李箱去新疆盯发酵罐"这种句子和 RAND 报告并排出现。

本站的图标是一条戴着安全帽的青色小鱼，正在把一块木板架到对面的悬崖上——<strong>它画的就是这个岗位：两道崖之间那段没人负责的路，得有人自己带板子过去。</strong>首页的桥形图、站徽、页脚和 404 页用的是同一套图形语言。

语气由 slogan 决定：**跑得快、不废话、给真东西**。落到这一站上，变成五条硬规矩：

## 内容纪律：三级可信度

全站只用三个等级标注事实，它们描述的是"能用到什么场合"，不是真假。

| 等级 | 含义 | 使用限制 |
| --- | --- | --- |
| `[A]` | 本站读到原始页面或文件，句子可逐字核对 | 可直接引用，建议把出处一起给出去 |
| `[B]` | 一手信息的可靠转述，或原文有但口径受限 | 引用必须带限定句：是预测、是广告价、是某一家的说法 |
| `[C]` | 从业者自述、自媒体整理、厂商或培训机构宣传 | 只用于说明"有人这么感受过"，不要写进正式材料 |

另有三条不可协商的写法约束：**美元 base 不与人民币月薪折算**；**预测不写成统计**（Gartner 那两句尤其如此）；**招聘广告数不写成成交数**（CNBC 那句限定必须一起抄走）。

## 技术实现

一页看懂的静态站，没有账号、没有跟踪、没有服务端。

| 项目 | 做法 | 为什么 |
| --- | --- | --- |
| 构建 | VitePress + Vue 3 + TypeScript，纯静态产出 | 内容站不需要后端；能被任何静态托管接走 |
| 图表 | 25 个自研图表组件（站内共 29 个 Vue 组件），全部服务端确定性渲染 | 不用图表库，不用 Math.random 与 window，SSR/CSR 一致，深色主题可控 |
| 字体 | 自托管可变字体（@fontsource） | 无 CDN 依赖、无首屏字体抖动、离线可构建 |
| 主题 | 品牌变量注入 VitePress 语义槽位；主动移除默认彩虹渐变标题 | 升级主题不丢设计；渐变字是"认真做品牌"的快速试纸 |
| 代码块 | 浅色主题下仍然是深墨绿 | 正文是纸，代码是终端，两者必须形成强对比 |
| 听书 | 浏览器原生 Web Speech API，零上传 | 不需要注册、不装 App、通勤可用；详见[听书怎么用](./listen.html) |
| 阅读顺序 | 单一数据源驱动侧边栏与连播队列 | 新增一页忘了登记，连播会静默停在上一页 |
| 明暗 | 两套完整 token，图表各自适配 | 不是简单反色；深色下面板、描边、强调色各有一套值 |

## 这本手册不做什么

<strong>不做职业规划。</strong>它不判断你"应该"转行，只提供判断材料。十题自评测的是偏好不是能力，也不预测 offer。

<strong>不做谈判代打。</strong>所有薪资数字都是公开区间或媒体实录，不是你该开口的价格。谈薪要用的锚点，是你自己那套可核验的经历与产出。

<strong>不做法律或合规意见。</strong>信创、等保、国密、验收与质保金那几节的写法是"这是现场会遇到的约束"，不是"你的系统应该怎么配置才合规"。这类问题只有客户的安全与法务部门能回答。

<strong>不做时效承诺。</strong>行情类数字的保质期通常只有几个月。本页抓取集中在 2026 年 10–11 月，个别数字来自 2026-11-03 发布的财报。引用任何一条之前，建议回原页看一眼日期。

## 发现错误怎么办

这类站最容易出的错是**转述失真**：把某家公司的 JD 摘要当成全行业结论，或者把媒体写的薪资当成官方公布数据。如果你在本站读到一条你手里有原文的数字，而两处对不上，那大概率是本站错了。

请带上三样东西来：出处链接、你读到的原句、本站那句话在哪个页面。**有这三样，一次反馈就够改完**；没有这三样，本站只能把它降级成 `[C]` 或者删掉——因为本站的规矩是宁可少一句，不少一个口径。
