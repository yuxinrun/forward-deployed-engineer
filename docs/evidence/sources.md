## 五、本站没能读到什么（这一节比上面重要）

**写清楚限制，是这本手册唯一能证明自己没有偷懒的方式。**

1. **国内主流招聘平台的岗位正文。** BOSS 直聘、猎聘、脉脉、拉勾的详情页需要登录或有反爬。本站能直读正文的非大厂样本只有极少数，因此国内薪资一律标注为"媒体实录或转述"，不写成"我们在岗位页上读到"。
2. **国内一手面经。** 本站没有找到可逐字引用的国内 FDE 面试亲历记录，所以面试章节里所有轮次、通过率与题型都明确标注为二手口径。
3. **工信部 414 号文的部委官网原件页。** 取到的是两处地市级政府网站的转发全文，且三处转发日期不一致。政策语境（培育服务商）与"职业工种/职称"的区分，因此在正文里被反复强调。
4. **Levels.fyi 的原始分布。** 抓取返回 405，未能回查。所以 Palantir 总包中位数只作量级参考，不进任何结论句。
5. **官方公布的面试通过率。** 没有任何一家公司公开过，所以漏斗图里四轮留白——留白是真的没有数字，不是省略。
6. **可点名的"国内大厂 FDE 团队的一天"。** 没有找到能直读的官方 JD 或官方叙述来描述国内大厂 FDE 的日常，因此相关章节只写了能从 JD 原文推出的部分，其余标为"未取到"。
7. **四份研究底稿里所有 `[C]` 条目的原始出处。** 例如"质保金 15%、押 18 个月""某公司 8 名 FDE 的结局"，都来自从业者自述或二手整理，本站无法回溯到原始当事人，因此全文只用于说明"有这种情况"，不用于给出行业结论。

## 六、方法说明

**怎么定等级。** 本站读到了原始页面且句子能逐字核对 → `[A]`；一手信息经由可靠转述（媒体报道的 JD 数字、聚合研究）→ `[B]`；从业者自述、自媒体整理、培训与厂商宣传 → `[C]`。等级标的是"能用到什么场合"，不是"真假"。

**怎么处理矛盾。** 不取平均、不做加权。四个互不兼容的失败率并排放，两份差旅比例不同的 JD 并排放，三套国内薪资口径并排放。**矛盾本身就是这一行当前的真实状态，把它抹平就是把信息抹掉。**

**币种与口径。** 美元区间一律写"招聘广告 base / 广告中位数"，人民币一律写"月薪档 / 年包（媒体实录）"，两者不做汇率折算，也不同图对比。

**时效。** 主要抓取集中在 2026-10 至 2026-11，个别数字（Palantir Q3 财报）来自 2026-11-03 发布。行情类数字的保质期通常只有几个月，引用前建议回原页看一眼日期。

::: tip 想自己复核
最快的路径是：先在本页第三节找到那条数字，点进原始材料核对句子，再看它在你打算使用的场合是否允许这么引。**如果一个数字经不起这一遍，它本来就不该出现在你的 PPT 里。**
:::
