# 硬数字速查表：每条带出处和等级

这张表的存在理由很简单：这一行的公开数字很多，能用的很少。<strong>同一个问题往往有三到四个互相矛盾的数，而差别几乎全部来自口径。</strong>所以本站把读到的数字集中放在这里，每条写清三件事：它统计的是什么、来源是什么等级、允许你拿它做什么。

等级含义：`[A]` 本站能逐字核对原文；`[B]` 一手信息的可靠转述，或口径受限；`[C]` 自述、转述、宣传材料。

## 怎么引用这张表

**可以：**"美国 FDE 招聘广告薪资中位约 19.5 万美元，约为全美岗位中位的 3 倍（Lightcast 口径，是广告不是成交）。"

**不可以：**"FDE 平均年薪 19.5 万美元，国内同行约 40 万元。"（混了口径、混了币种、还把广告当成交）

**最推荐的用法**是反过来：拿一条数字问"它统计的是什么"。这一行绝大多数夸张结论，在回答这个问题之后会自动缩小到可以接受的范围。

出处逐条链接在<a href="./sources.html">调研底稿与出处</a>；怎么把这些数字用在与雇主谈薪的场合，见<a href="../market/salary.html">薪酬：中外区间与总包口径</a>；怎么在面试里引用它们，见<a href="../path/interview.html">面试怎么考</a>。
